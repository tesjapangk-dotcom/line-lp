# 総務タスク管理アプリ 仕様書

作成日：2026-07-04

---

## 概要

総務部門の年間タスクをスプレッドシートで管理し、Google Apps Script (GAS) でウェブアプリとして公開するタスク管理ダッシュボード。

## スプレッドシート構成

| 列インデックス | 列名 | 内容 |
|--------------|------|------|
| 0 | ID | タスクID |
| 1 | 月 | 対象月（例：4月、5月） |
| 2 | 実施時期 | 月内の実施時期（例：月初、月末） |
| 3 | タスク名 | タスクの名称 |
| 4 | カテゴリ | タスクのカテゴリ |
| 5 | 完了 | 完了ステータス（`完了` または空白） |
| 6 | 担当者 | 担当者名 |
| 7 | リマインダー送信済 | リマインダーの送信状況 |
| 8 | __PowerAppsId__ | PowerApps連携用ID |

- **総タスク数**：198件
- **対象期間**：4月〜3月（年度）

---

## 機能一覧

### ダッシュボード画面
- 今月の完了率（プログレスバー）
- 完了・未完了・合計の件数表示
- 月別完了件数の横棒グラフ
- 直近の未完了タスク一覧（最大20件）
- 「📅 年間スケジュール一覧」ボタン

### 年間スケジュール画面
- ボタンを押すと同一ページ内に表示（URLは変わらない）
- 4月〜3月の年度順に月別グループ表示
- 各月：タスク名・実施時期・完了ステータスをテーブル表示
- 月ごとの完了件数表示（例：3/15件完了）
- 「← ダッシュボードに戻る」ボタン

### タスク完了登録
- URLパラメータ `?id=タスクID` でアクセスするとスプレッドシートの該当行の「完了」列に `完了` を書き込む
- 主にLINEリマインダーからのリンクとして使用

## ファイル内容

### コード.gs（サーバー側）

```javascript
function doGet(e) {
  var action = e.parameter.action;
  var id = e.parameter.id;

  if (id) {
    var ss = SpreadsheetApp.openById('1yOVyImQuWwoymoz2uX3hzltZzgiKmaF3ByGRQ6qOcng');
    var sheet = ss.getSheets()[0];
    var data = sheet.getDataRange().getValues();
    var header = data[0];
    var idCol = header.indexOf('ID');
    var statusCol = header.indexOf('完了');
    for (var i = 1; i < data.length; i++) {
      if (String(data[i][idCol]) === String(id)) {
        sheet.getRange(i + 1, statusCol + 1).setValue('完了');
        return HtmlService.createHtmlOutput('<p style="font-family:sans-serif;padding:20px;color:green;">✅ 完了にしました</p>');
      }
    }
    return HtmlService.createHtmlOutput('<p style="font-family:sans-serif;padding:20px;color:red;">❌ 見つかりませんでした</p>');
  }

  return HtmlService.createHtmlOutputFromFile('index');
}

function getData() {
  var ss = SpreadsheetApp.openById('1yOVyImQuWwoymoz2uX3hzltZzgiKmaF3ByGRQ6qOcng');
  var sheet = ss.getSheets()[0];
  var data = sheet.getDataRange().getValues();
  var header = data[0];
  var monthCol = header.indexOf('月');
  var periodCol = header.indexOf('実施時期');
  var taskCol = header.indexOf('タスク名');
  var statusCol = header.indexOf('完了');
  var result = [];
  for (var i = 1; i < data.length; i++) {
    result.push({
      month: data[i][monthCol] || '',
      period: data[i][periodCol] || '',
      task: data[i][taskCol] || '',
      status: data[i][statusCol] || ''
    });
  }
  return result;
}
```

## 技術メモ

- GASウェブアプリはコードを変更しても**デプロイ（新しいバージョン）しないと反映されない**
- `google.script.run.withSuccessHandler(fn).getData()` でクライアントからサーバー関数を呼び出す
- 年間スケジュールはURLを変えずに同一ページ内でshow/hideで切り替える方式を採用（URLルーティング方式はGASの制約で不安定なため）
- スプレッドシートの「完了」列はテキスト `完了` で管理（チェックボックスではない）
